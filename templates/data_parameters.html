Understanding Data Parameters

ATR Interval - The timeframe used for calculating the Average True Range, which affects stop loss and take profit levels.

Price Data Interval - The timeframe for price data used in signal generation.

Price Results Count - The number of price candles to fetch. More data points provide more accurate percentile calculations but require more API calls.

Note: Changing these parameters will affect signal generation. Smaller timeframes provide more signals but may be noisier. Larger timeframes provide fewer, potentially higher-quality signals.
