Setting Up Telegram

How to set up Telegram notifications:

  1. Create a new Telegram bot using @BotFather
  2. Get your chat ID by sending a message to @userinfobot
  3. Construct your webhook URL using this format: https://api.telegram.org/bot[BOT_TOKEN]/sendMessage?chat_id=[CHAT_ID]
  4. Enter this URL in the field above
  5. Make sure to message your bot first to allow it to send you messages

Testing your webhook:

After saving your webhook URL, the system will use it when generating signals. You can manually trigger a signal generation run to test if your Telegram notifications are working correctly.
